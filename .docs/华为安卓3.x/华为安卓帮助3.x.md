# 华为安卓帮助

## 操作流程

### cocos 3.x
1. 项目 -> 构建发布：游戏名称（英文名称，例：2001_XiaoHeiTeNiu）、包名、agconnect-services 配置（settings/agconnect-services.json）;

   ![cocos 构建](<cocos 构建 1.png>)
   
   ![cocos 构建](<cocos 构建 2.png>)
2. 更新广告框架 **`.tools/.bfy-upgrade/bfy-upgrade-hwapk.bat`**；
3. 将 **`agconnect-services.json`** 文件复制到app文件夹里;

   ![agconnect-services](<agconnect-services.png>)
4. AndroidStudio HUAWEI App 打开路径：**`项目\build\huawei-agc\proj`**
5. AndroidStudio: **`File -> Settings -> Build, Execution, Deployment -> Build Tools -> Gradle -> Gradle Projects -> Gradle JDK -> jdk-17.0.17 -> OK`**;

   ![Settings Gradle](<Settings Gradle.png>)
6. AndroidStudio: Sync Project with Gradle Files（右侧顶部小象按钮）；
7. 换图标 AndroidStudio: Android -> 游戏名称 -> res -> 删除 mipmap -> 右键 -> New -> Image Asset -> Path -> Resize 70% -> Next；
   - 7.5 instantapp 项目需要同样的添加一份图标资源；
   
   ![Android mipmap](<Android mipmap.png>)
8. .java 项目命名空间替换: **`downLoadNativeAd、NativeAdManager、NetWorkPop、PrivacyPolicyManager、SplashActivity`**；
   
   ![Android java](<Android java.png>)
9. Build Variants: 左侧菜单栏 -> ... -> Build Variants -> 设置所有未 release ；
   
   ![Build Variants](<Build Variants.png>)
10. 版本号修改: 1.0.0.2 默认测试版本号；
   
   ![Gradle Version](<Gradle Version.png>)
11. Build；
